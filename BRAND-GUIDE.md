## 1. Brand Foundation

### What muteflow is

muteflow is the technical fulfilment team behind AI agencies who close faster than they can ship. We build the automations, voice agents, and AI workflows our clients' clients bought — under their brand, inside their timelines, without their clients ever knowing we exist.

### The brand promise in one line

> We build it. You take the credit.

### Core brand attributes

| Attribute | What it means in practice |
|---|---|
| **Silent** | We never appear on client calls, in client emails, or in client-facing deliverables. Every asset we ship is unbranded to us. |
| **Technical** | We speak the language of engineers, not marketers. Named tools, named capabilities, named outcomes. |
| **Invisible** | Our value is proportional to how unknown we are. We measure success by how little our clients' clients know about us. |
| **Continuous** | Automations, workflows, and systems that don't break at 3am. Muteflow is infrastructure, not a service call. |
| **Non-competitive** | We have never taken a client-facing AAA engagement. We never will. |

## 2. Logo System

### The primary wordmark

The muteflow wordmark is the single, load-bearing visual asset of the brand. It is always rendered in **lowercase**, set in **Inter Display at weight 800** with a **letter-spacing of -0.045em**.

There are three load-bearing elements:

1. **The wordmark itself** — `muteflow` as a single unbroken word. Never hyphenate, never split into two words, never mix cases.
2. **The flow bar** — a 3px accent line extending from the baseline of the wordmark. This represents the continuous, silent signal that muteflow carries beneath the client agency's brand. It is the visual enactment of "flow."
3. **The signal dot** — a single lime circle at the end of the flow bar. This represents the "operational" status — the green light on a running system. It communicates reliability without words.

### Symbolism

- **The lowercase setting** performs the brand's core promise. Uppercase shouts. CamelCase waves for attention. Lowercase simply works.
- **The unbroken wordmark** ("mute" and "flow" merging with no visible seam) reflects how muteflow integrates invisibly into a client agency's operations — no handoff seam is ever visible to the end client.
- **The flow bar** is a literal current — it runs beneath the wordmark the way muteflow's engineering runs beneath an agency's brand.
- **The signal dot** is the smallest possible proof of life: the system is running, everything is fine, you can stop thinking about it. Exactly what a scared agency owner needs to feel.

### Logo variants

| Variant | Background | Use case |
|---|---|---|
| **Primary (dark)** | #0A0A0B / dark surfaces | Default. Website, social, pitch decks, email signatures. |
| **Light** | #FFFFFF / light surfaces | Print collateral, invoices, white-background presentations. |
| **Monochrome** | Transparent / any | Single-colour applications: embossing, stamps, embroidery, favicons on varied backgrounds. |
| **Favicon** | #0A0A0B rounded tile | Browser tabs, app icons, social avatars. |

## 3. Logo Specifications

### Clear space rule

Minimum clear space around the wordmark equals the **x-height of the lowercase letters** (the height of the "u" or "o"). No text, imagery, or interface chrome may sit within this invisible margin.

```
┌──────────────────────────────────────┐
│                                      │
│   [x]                         [x]    │
│   ┌──────────────────────┐           │
│   │                      │           │
│   │      muteflow        │           │
│   │      ▔▔▔▔▔▔▔▔•       │           │
│   │                      │           │
│   └──────────────────────┘           │
│   [x]                         [x]    │
│                                      │
└──────────────────────────────────────┘

x = height of lowercase letter
```

### Minimum size

| Medium | Minimum width |
|---|---|
| Digital screen | 88px |
| Print | 24mm |
| Favicon version only | 16px |

Never render the full wordmark below 88px — at smaller sizes, use the favicon `m` variant instead.

### What NOT to do with the logo

The brand integrity rules below are non-negotiable. Any violation weakens the silent-operator positioning we've built.

| ❌ Don't | Why it breaks the brand |
|---|---|
| Capitalise any letter. "Muteflow" or "MuteFlow" in the wordmark | Uppercase shouts. The entire brand is named after silence. |
| Add an icon, mascot, or illustration next to the wordmark | The wordmark is the mark. Adding anything dilutes it. |
| Rotate the wordmark or set it at an angle | muteflow is steady, horizontal, structural. Never tilted. |
| Apply drop shadows, outer glows, or bevel effects | Every effect added is a piece of trust removed. |
| Recolour the wordmark in any colour other than the approved palette | Exactly two acceptable fills: #F4F4F5 (dark backgrounds) or #0A0A0B (light backgrounds). |
| Change the font, weight, or letter-spacing | The wordmark is not type. It's a locked asset. |
| Place the logo on busy photography or low-contrast backgrounds | Always on solid colour or heavily blurred gradient. |
| Stretch, squash, or distort the proportions | Geometric ratios are fixed. Scale uniformly or not at all. |
| Recreate the wordmark manually by typing "muteflow" in any font | Always use the approved SVG/PNG files. |
| Use the favicon `m` as a standalone logo | The favicon is functional only. The wordmark is the brand. |

## 4. Colour Palette

### Primary palette

The primary palette is designed for dark-mode dominance. Every colour earns its role — none are decorative.

| Token | Hex | RGB | CMYK | Role |
|---|---|---|---|---|
| **Void** | `#0A0A0B` | `10, 10, 11` | `91, 90, 86, 77` | Primary background |
| **Elevated** | `#111113` | `17, 17, 19` | `89, 88, 83, 75` | Cards, nav, surfaces |
| **Border Quiet** | `#1F1F23` | `31, 31, 35` | `85, 83, 69, 60` | Dividers, borders |
| **Signal** | `#C4F547` | `196, 245, 71` | `32, 0, 92, 0` | Primary CTA, accent only |

### Secondary palette

| Token | Hex | RGB | CMYK | Role |
|---|---|---|---|---|
| **Text Primary** | `#F4F4F5` | `244, 244, 245` | `0, 0, 0, 4` | Headlines, body copy |
| **Text Muted** | `#A8A8B3` | `168, 168, 179` | `6, 6, 0, 30` | Subtext, descriptions |
| **Text Quiet** | `#8A8A93` | `138, 138, 147` | `6, 6, 0, 42` | Captions, eyebrows |
| **Text Ghost** | `#6A6A73` | `106, 106, 115` | `8, 8, 0, 55` | Metadata, deep background copy |

### Neuromarketing reasoning

- **Void (#0A0A0B)** is not pure black. The 1.5% warm bias reads as intentional and engineered rather than cheap or OLED-default.
- **Signal Lime (#C4F547)** was chosen deliberately over the industry-default blue or purple. It carries three psychological associations that matter for this buyer: *active systems* (terminal green, monitoring "online" indicators), *unmissable contrast* (14:1 ratio against void), and *category differentiation* (zero other AAAs use lime). Deploy signal lime a maximum of three times per page.
- **The text ladder** is designed for fifteen-minute reading sessions. True white (#FFFFFF) on dark is exhausting; #F4F4F5 reduces eye strain while still reading as "crisp."

### Colour usage ratio (per page)

| Role | % of visual real estate |
|---|---|
| Void + Elevated + Border Quiet | 85% |
| Text Primary + Text Muted | 12% |
| Signal Lime | ≤3% |

**The scarcity of Signal is what makes it work.** If you use lime more than three times on a page, you have ceased to be a silent operator brand.

## 5. Typography

### Type system

muteflow uses a deliberately narrow type system. Fewer fonts means tighter brand memory.

| Role | Font | Weights | Reason |
|---|---|---|---|
| **Display / Headlines** | Inter Display | 700, 800 | The standard for premium B2B tech in 2026. Used by Linear, Vercel, Cal, Stripe. Fighting this for differentiation loses. |
| **Body / Paragraph** | Inter | 400, 500 | Peerless legibility at 15–18px. Pairs seamlessly with Inter Display. |
| **Monospace / Technical** | JetBrains Mono | 500 | For case labels, stat numbers, code-adjacent moments. Signals *built by engineers* without saying it. |

### Typography rationale for this brand specifically

**Why Inter and not something more distinctive?**

Our buyer — the AAA owner — spends their working life inside tools set in Inter. Linear, Vercel, Notion, GitHub, Raycast, Stripe Dashboard, Supabase, OpenAI, Anthropic. Inter is not "generic" to this audience; it is the familiar. Our brand differentiation comes from composition, colour, and voice — not from forcing a quirky display face.

**Why JetBrains Mono for technical accents?**

JetBrains Mono is the default typeface of serious engineering environments. When a technical founder sees JetBrains Mono, their brain registers *competence* before they read a single word. We use it for case labels (`CASE 01 / An AAA in Austin`), stat numbers, and any "code-like" moment. It's the typographical equivalent of wearing a black hoodie to a Stripe engineering meeting — dress code as trust signal.

### Type scale (desktop)

| Level | Size | Line height | Letter spacing | Weight |
|---|---|---|---|---|
| H1 | 72px | 1.05 | -0.045em | 700 |
| H2 | 48px | 1.10 | -0.035em | 700 |
| H3 | 24px | 1.30 | -0.02em | 600 |
| Body Large | 19px | 1.55 | 0em | 400 |
| Body | 17px | 1.55 | 0em | 400 |
| Small | 14px | 1.50 | 0em | 400 |
| Eyebrow | 12px | 1.00 | 0.12em (uppercase) | 600 |

### Type scale (mobile, ≤768px)

All headlines scale down using `clamp()` in CSS. H1 floor: 48px. H2 floor: 36px.

## 6. Brand Voice & Tone

### Voice principles

The voice of muteflow is **authoritative, direct, and quietly confident** — the voice of a senior engineer who respects your time. Think less "brand copywriter" and more "the technical lead in your Slack workspace who always has the right answer."

### The five voice rules

**1. Declarative, not aspirational.**
Say what we do, not what we believe in. "We build under your brand" — not "We believe in empowering agencies to scale."

**2. Short sentences. Shorter paragraphs.**
Technical founders skim. Every paragraph is one idea, maximum three sentences. If a sentence can be cut in half, cut it.

**3. Named over abstract.**
"ElevenLabs · Vapi · Retell · Twilio" beats "industry-leading voice platforms" every time. Every time.

**4. Silence is the flex.**
Don't claim expertise — demonstrate it through specificity. Don't advertise clients — refuse to name them. Don't promise — state policy.

**5. Earned humour only.**
Occasional dry wit is on-brand ("We have never taken a client-facing AAA engagement. We never will.") Never jokes, never puns, never emojis in marketing copy.

### Words we use

*build, ship, scope, deliver, operate, infrastructure, handoff, under your brand, behind, silent, quiet, disappear, non-compete, non-solicitation, retainer, production-grade, sub-second, audit trail*

### Words we never use

| ❌ Word / Phrase | ✅ Use instead |
|---|---|
| "Partner" / "partnership" | "Build team" / "fulfilment team" |
| "Solution" | "Build" / "system" / name the specific tool |
| "Revolutionary" / "cutting-edge" / "game-changing" | Specific metric or named capability |
| "Empower" / "unlock" / "unleash" | "Build" / "ship" / "deliver" |
| "Synergy" / "leverage" / "ecosystem" | Use plain English |
| "Journey" | "Build" or "engagement" |
| "Passionate about" | Nothing. Cut the sentence. |
| "World-class" / "best-in-class" | Let the work speak. Or name the stack. |

### Voice in practice — side-by-side

| ❌ Wrong tone | ✅ muteflow voice |
|---|---|
| "We empower AI agencies to unlock scalable fulfilment solutions." | "We build the systems your agency sold. Under your brand. On your timeline." |
| "Our passionate team of experts is ready to partner with you on your AI journey." | "Scope a build. We'll confirm scope, stack, and timeline within one business day." |
| "Welcome to muteflow — your trusted partner in digital transformation!" | "muteflow is the technical fulfilment team behind AI agencies." |

## 7. Iconography & Imagery

### The photography rule

**muteflow does not use stock photography. Ever.**

No laptops on marble desks. No diverse smiling teams in meeting rooms. No fibre-optic cable close-ups. No abstract 3D renders with blue gradient blobs. The moment stock enters the brand, the "silent operator" premium positioning collapses.

### What we use instead

**1. Typography as imagery.**
The site is 90% composed of text, spacing, and colour. Large headlines act as the visual feature of the page.

**2. Technical artefacts, rendered in-brand.**
When we need to show something, we show the actual work — rendered using our palette:
- Scenario screenshots from Make.com, styled to our palette
- Code snippets in JetBrains Mono with our colour tokens as syntax highlighting
- Architecture diagrams drawn in monoline SVG, never filled illustrations
- Terminal output mock-ups with the signal lime cursor

**3. Abstract atmospheric elements.**
- Subtle animated gradient meshes in the hero (grainy, slow, low opacity — always at ≤6% opacity)
- Thin 1px borders on cards in Border Quiet (#1F1F23)
- Grain overlay at 3% opacity across the entire site for tactile warmth

### Iconography

**Icon library: Lucide** (lucide.dev) — stroke-based, monoline, consistent with Linear's aesthetic.

**Icon rules:**

| Rule | Detail |
|---|---|
| Stroke weight | 1.5px, always |
| Colour | Text Muted (#A8A8B3) by default. Signal Lime only for primary CTAs. |
| Fill | Never. Always outlined. |
| Custom icons | If we need one not in Lucide, we draw it in the same monoline style. |
| Size | 16px, 20px, or 24px. Never in between. |

### What NOT to use for iconography

- Emoji in any marketing context (acceptable in internal Slack only)
- Gradient-filled icons
- Isometric illustrations (the "Corporate Memphis" style and its descendants)
- Any icon that includes a robot, a brain, a lightbulb, a rocket, or a checkmark-inside-a-shield

### Signal lime — the one decoration that's allowed

A single lime-accented element can appear as a quiet visual rhythm marker:

- A 6px pulsing dot next to a status ("OPERATING QUIETLY")
- A 3px underline beneath a key word in a headline
- The cursor in a code snippet
- The primary CTA button

**Never more than three instances per page.** Scarcity is what makes the colour work.

## 8. Usage Examples

### Email signature

```
—
Bilal
muteflow
bilal@muteflow.io
muteflow.io
```

*Set in Inter at 14px, no banner image, no social links. The signature is the signal.*

### Social avatar

Use the favicon (#0A0A0B tile, lime "m", 48px rounded corners) at any social platform that requires a square. Never use the full wordmark — it becomes illegible below 88px.

### Cover photo / LinkedIn banner

- Background: #0A0A0B solid or with subtle lime radial gradient at 6% opacity in one corner
- Wordmark: centred or left-aligned at 1/4 canvas width
- Tagline beneath (optional): "The silent build team for AI agencies." in Inter 500, Text Muted

### Document headers (proposals, SOWs, invoices)

- Wordmark top-left at 180px width
- Document type top-right in JetBrains Mono uppercase (`SCOPE OF WORK` or `INVOICE #0042`)
- Hairline rule in Border Quiet across the page beneath

### Slack / Notion workspace

- Workspace icon: favicon
- Workspace name: `muteflow` (lowercase)
- Default channel colour accent: signal lime
- Workspace banner, if shown: #0A0A0B solid
